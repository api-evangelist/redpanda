# Redpanda (redpanda)

Redpanda is a Kafka-compatible streaming data platform written in C++ with no JVM and no ZooKeeper, optimized for low latency and operational simplicity. The Redpanda Cloud API exposes clusters, topics, ACLs, and serverless namespaces.
